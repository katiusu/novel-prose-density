# 可选扩展：亲密场景用词与节奏

> 本文是 `SKILL.md` 的可选补充，不是独立规范。文风、句长、逗号、模具配额一律以 `SKILL.md` 为准；本文只补充用词与节奏上的差异项。

## 0. 触发与叠加方式

前置：先读 `SKILL.md`。正常叙述不需要本文。

只在正文出现下列内容时叠加本层：性爱、自慰、口交、手指、道具、前戏调情、边缘控制、压力型调教（憋尿一类）、事后善后。

叠加规则：

- **文风不动**：句子长度、逗号密度、慢镜头、拟声词、模具配额、禁句式，全部以 `story-prose-dense` 为准，本 skill 不覆盖它们。
- **只加四件事**：实名铁律（§1）、体液来处去向（§2）、露骨细节三层与轮数（§3、§4）、压力型场景（§6）。
- 一章之内可以切换：进入身体段就叠加，退出身体段就回通用层，不需要全章统一腔调。
- 非色情段落不套本 skill，也不必强行塞器官词。

## 1. 铁律：实名（隐喻代称同样禁止）

不许用任何代称、雅称、婉辞、借代、昵称、暗示词指性器官、体液、性行为。**一个都不许**，包括"文学化"的、"看起来很美"的、"业内通用"的。

| 类别 | 禁例 |
|---|---|
| 指示性代称 | 那处、那里、这边、下面、底下、私处、要害、关键部位、敏感的地方、那一带、某处 |
| 位置隐喻 | 三角地带、那片领地、丘陵、山谷、花园、最私密的地方、腿间那一小块 |
| 形态隐喻 | 那道缝隙、那道口子、那道皱褶、花瓣（单独作主语时） |
| 通道隐喻 | 甬道、腔道、深处（单独作主语时）、通道 |
| 昵称化 | 小豆豆、小核、那颗珠子、那粒宝贝 |
| 代词指部位 | 它、它们、那东西、那玩意儿、那股、那一团、那一层 |
| 雅化借代（白名单外） | 幽谷、桃源、玉门、玉茎、甘露、情潮、春潮、欲火 |
| 抽象化 | 快感（作唯一主语时）、感觉、刺激、某种东西 |
| 体液代称 | 一股温、一股热、那点液体、湿意、水光（指淫水时）、分泌物、晶莹的液体 |
| 模糊动词 | 做了、进入了她、要了她、给了她、弄了弄、动作起来 |

**默认写法：直呼其名。** 阴唇、阴蒂、阴核、小穴、穴口、阴道口、内壁、子宫口、肛门、乳头、乳尖、臀部、大腿内侧、手指、舌头、舌尖、尾巴、淫水、尿、黏液、口水、潮吹、精液。

### 1.1 明喻与实名同现

浓稠修饰可以留，**但修饰必须落在实名上，不能替代实名**：

- 合法：`如同花瓣般娇嫩的阴唇`、`硬得像一颗要熟的果子的阴蒂`
- 违规：`那道花瓣般娇嫩的缝隙`、`那片小小的丘陵`、`最深处的嫩肉`

判定只看一句：把这句里的隐喻全部删掉，**还知不知道指的是哪个部位**。知道，合法；不知道，就是代称。

### 1.2 白名单雅称（作者已批准）

`花穴`、`蜜穴`、`花蜜`、`蜜液`、`爱液`、`银丝`。六个词不算违规，前提四条：

1. **指向明确**：`花蜜`/`蜜液`/`爱液` 要跟"从穴口流出""挂在阴唇上"这类来处去向连写，不许单说"淌出蜜液"。
2. **不作唯一主语**：一段之内至少出现一次解剖实名。
3. **同段不混用**：一段里选一个用到底，别在蜜液/爱液/花蜜之间来回换。
4. **明喻化用法优先实名**：`那片花穴` 不如 `阴唇之间的穴口`。

**人称代词完全自由**：她／他／我／你，指人随便用；`它/它们` 指人（含亚人种族的非人自称、兽形、物件化代称）同样合法。禁的只有一件事：用代词去指**部位或体液**。

### 1.3 改写对照

| 错 | 对 |
|---|---|
| 手指按上那处，她抖了一下 | 手指压在阴蒂上，她抖了一下 |
| 一股温顺着腿根淌下来 | 尿顺着腿根淌下来／淫水顺着腿根淌下来 |
| 它抵在穴口，慢慢往里 | 龟头／手指／尾巴尖抵在穴口，慢慢往里 |
| 我进入了她 | 我把阴茎推进小穴，推到指根／整根没入 |
| 那里已经湿了 | 阴唇已经湿了／穴口挂着淫水 |
| 那片小小的丘陵上，没有一点毛发 | 阴阜上没有一根毛，皮肉绷得发亮 |
| 探入甬道深处 | 探进阴道，指尖顶到内壁尽头 |
| 那颗小豆豆在我指下跳 | 阴蒂在我指腹底下跳 |

## 2. 体液与声音：写清来处、路径、终点

- 淫水：从穴口出来、挂在内壁上、顺着会阴淌到肛门、滴到床单上、被手指带出拉成丝、被舔进嘴里。
- 尿：失禁时从尿道口出来、顺着大腿内侧、打湿裙摆或丝袜、在地板上积一小片、被床单吸掉。
- 潮吹：喷在手背上、喷到对方脸上、落在水面上。
- 黏液与口水：拉丝、挂在下巴上、蹭在颈侧、被舌头卷走。
- 声音：水声（`咕啾`）、拍打声、布料摩擦、尾巴扫过、膝盖撞到床板、门外脚步声。

写体液必须回答两件事：**从哪出来，流到哪去**。只写"湿了"是无效描写。

## 3. 露骨细节三层（每 100 字至少一处）

1. **外部动作**：谁的手在哪、几根手指、多深、什么角度、谁按着谁、衣服到哪一步。
2. **身体反应**：哪处先动、哪处后动、肌肉怎么绷、呼吸怎么断、皮肤起什么反应、腿夹紧又松开。
3. **体内感受**：被撑开的胀、被顶到的酸、内壁被磨的麻、小腹里的坠、高潮前的收与绞。

三层轮着写，不许停在"很舒服""受不了""快要到了"这类概括句上。

## 4. 动作递进与轮数

- 前戏 → 主体 → 余韵，三段都要落笔。余韵写腿软、水凉了、对方替你拉被子、地板上的水迹还没干。
- 普通场 ≥3 处露骨描写；重点场（S 级）≥5 处，并且至少 5 轮动作。轮间必须换变量：
  手指 → 口舌｜一根 → 两根｜前面 → 后面｜床上 → 墙边 → 地上｜衣物 → 全裸｜被动 → 自己动｜外部压力 → 内部快感｜羞耻 → 索要
- 连续高潮允许写两次以上；第二次写敏感叠加：碰一下就抖、缩、躲、又被拉回来。
- **不淡出、不快进、不写"接下来不必细说"**。事后善后照样写：擦、洗、抱、穿衣服。

## 5. 同意与视角

- 主角全自愿，主动权只体现在"允许"和"索要"上。把手指按回去、把腰送上去、抓住对方的手不放、明明能躲却不敢动，都是同意，不需要口头许可。
- 人称以 `story-prose-dense` §5 为准（完全自由），本层只查一件事：同一场景内有没有跳人称、手的归属有没有打架。
- 不写被削弱的人格：绷不住、受不住、被按住属于情动；叫停就停是底线。压力型场景另见 §6。

## 6. 压力型场景（憋尿、边缘控制、威胁话术）

引擎不是快感，是**一个外部压力源与快感对冲**，简单好用，但最容易写崩。

- **只用一个压力源**：憋了多少、什么姿势能憋住、还剩多少时间，这三件事要在第一轮之前交代干净，中途不再加新压力。
- **压力要能被看见**：小腹鼓到什么程度、皮绷得怎样、尿道口有没有鼓起来、腿夹到什么份上。压力是身体状态，不是台词。
- **同意信号这样写**：把腰往上送、抓着床单不放、嘴里说着不要腿却张得更开、听话地一动不动、主动问"还能不能忍"。
- **痛感词换成受不住**：受不住、绷不住、炸开、塌下去、麻到没知觉。`凄厉`、`绝望`、`撕心裂肺`、`生不如死` 一律不用，这类词把情动写成受刑，人物就废了。
- **威胁必须有落点**：说出口的威胁，下文要么兑现要么撤回，不许悬空收场。
- **收尾必须写失禁之后**：床单怎么处理、谁擦的、抱了多久、尾巴收回去没有。压力型场景的余韵比高潮本身重要。

## 7. 交稿前自查

1. 跑脚本清零：`python3 scripts/check_erotica.py 正文/第NNN章.md`
2. 每个器官、每次体液出现时问一句"这是名词还是代称"。
3. 数露骨处数与轮数，够不够本章档位；轮间换了几个变量。
4. 体液有没有写来处与去向。
5. 压力型场查六条：单一压力源、压力可见、同意信号、痛感词、威胁落点、失禁之后的收尾。
6. 风格项回 `story-prose-dense` §8 自查（逗号、句末单字、模具配额）。

## 8. 自查脚本

```bash
python3 /root/.agents/skills/story-erotica-direct/scripts/check_erotica.py 正文/第001章.md
```

- **强禁（HARD）**：私处／那东西／分泌物／一股温／三角地带／甬道／小豆豆／晶莹的液体 等词表命中即违规；`缝隙`／`皱褶`／`丘陵`／`山谷`／`口子`／`嫩肉`／`领地` 这类软词，**同行没有解剖实名时**判违规（`花瓣般娇嫩的阴唇` 合法，`花瓣般娇嫩的缝隙` 违规）。
- **语境代称（CTX）**：那处／那里／底下／下面／上头／那一层／它／它们，同一行出现解剖实名或手、指、唇、腿等身体动作词时才判违规；`膝盖底下`、`尿道口底下`、`太阳底下`、`被子底下` 这类空间用法自动放行。
- **弱提示（TIP）**：快感／感觉／刺激／某种，只提示，人工判断是不是概括句。

白名单 `花穴 蜜穴 花蜜 蜜液 爱液 银丝` 在脚本与本文档中**一致**放行（旧版 §10 曾把它们列进强禁，与脚本冲突，已修）。

风格项（句末单字、模具配额、逗号密度）不在本脚本，见 `story-prose-dense` §9。

## 9. 文风锚点（露骨层的密度参考）

> 我把中指从她小穴里抽出来时穴口还含着半截指节不肯松开，一直抽到指根穴口自己松开并牵出一长串透明的淫水，从我的指尖连到她的阴唇坠成一条细丝晃了两下断掉、滴在她小腹那道绷得发亮的弧线上。

> 我用那根湿透的手指顺着那道弧线往上抹，把淫水一路涂到她的肚脐留下一片水痕，然后整只手掌覆上去压住小腹正中那块鼓得最满的地方，皮在我掌心底下撑得很薄、绷得像一只吹到极限的气球。

这一段可核对的量：逗号 2 个 / 约 100 字，明喻 1 个且落在身体上，`充满` 0，代称 0，`才` 0，露骨动作 4 步不换段。
